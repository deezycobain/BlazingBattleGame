# v0.5.25 Inventory UI

Added as a UI-only branch on top of v0.5.24.

Active owned units: Crimson, Sub-Zero.

Flow: Main Menu -> Inventory -> Fighter Details -> View Art.

Design references are stored in `_design_references/inventory/` and are not runtime assets.
Sub-Zero detail/full art supplied by the user are stored under `assets/characters/subzero/cards/` and `assets/characters/subzero/art/`.
Crimson currently uses his approved battle sprite on the collection card until a dedicated full artwork is supplied; no unrelated legacy card art is shown.

No battle mechanics were modified.
