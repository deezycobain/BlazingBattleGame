# Lebee Basic Range + Link HUD — v0.6.2

## Star Blast
Lebee's normal attack is now a true ranged lane attack.

Canonical basic shape:
- rectangle: 250 px long
- 72 px wide
- 112 px forward offset from Lebee
- rotates with her facing direction

The visible rectangle and mechanical hit detection use the same geometry.

Enemies in the lane receive a pulsing cosmic-magenta target bubble.

## Link Attack top bar
When the active team is linked, the top tactical notification bar now remains visible
during attack preview and reports:

`LINK ATTACK ×2 · <damage> DMG`

Any active Link ATK percentage remains shown beside it.

## Not changed
Meteor Jutsu, stats, team selection, Sub-Zero, Crimson, boss HUD, and the v0.6.0 master.
