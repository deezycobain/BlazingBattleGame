# Road Rookie Four-Frame Idle Pilot

This is a **dev-only Animation Lab preview** for the 2026-10-19 Road Rookie
idle review. It contains four independently validated 512×768 RGBA frames at a
180ms starting cadence.

It is not an Atlas Contract v1 asset: it is deliberately not a six-frame 3×2
atlas, has no Contract v1 metadata, and is not wired into combat, collection,
summon, Road, or save behavior. Producer review is still required before any
runtime migration.
