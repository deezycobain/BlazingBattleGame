# Scorpion idle — browser test proof

This folder is a lightweight review bundle for the first full-body Scorpion idle test.

- 24 frames
- 24 FPS sequence
- 1.0-second seamless loop
- Three-quarter gameplay-facing guard
- Grounded foot baseline; subtle breathing only

## Files

- `scorpion_idle_preview_24fps.gif` — browser-playable animation review. It is downscaled for quick GitHub loading; the GIF uses 40/50 ms frame delays to preserve 24 frames in one second within the GIF format's centisecond timing.
- `scorpion_idle_contact_sheet.png` — labeled 24-frame review board.

Open `/scorpion-idle-proof-test.html` from this branch to assess the loop in a browser. This test bundle is intentionally lightweight; it does not replace the source RGBA PNG sequence and atlas package.
