# Blazing Battle Home UI Assets

Approved Home UI direction for the Persona-inspired / anime-world-navigation redesign.

## Runtime folders
- `navigation/` — Battle, Summon, Units, Forge
- `utility/` — Missions, Inbox, Shop, Settings, Chat, Friends, Menu
- `hud/` — player profile and currencies
- `controls/` — carousel arrows/dots, notification badge, plus control, carousel frame
- `banners/` — promo frames and NEW / EVENT / LIMITED tags
- `backgrounds/` — approved Home-scene concepts
- `reference/` — approved visual reference sheets / target composition

All runtime images are WebP, optimized for the mobile UI. Keep the original generated PNG sources outside runtime loading unless a later art pass requires them.
